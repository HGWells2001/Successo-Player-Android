# Successo Player Android

Player Android non ufficiale dedicato a **“Successo. Storie e voci dal Novecento”** di RaiPlay Sound.

## Versione corrente

**v3.3 – Filtro puntate ascoltate**

## Funzioni principali

- catalogo delle puntate da RaiPlay Sound;
- riproduzione audio in foreground/background;
- ripristino della sessione quando si passa ad altre app;
- download delle puntate con avanzamento;
- preferiti ★;
- indicatore **✓ Ascoltata**;
- filtro **Preferite** e filtro **Ascoltate**, combinabili con la ricerca;
- modalità **Shuffle** con continuazione casuale automatica;
- riproduzione automatica della puntata successiva con Shuffle disattivato;
- notifica delle nuove puntate;
- popup giornaliero con alba, tramonto e fase lunare a Saxa Rubra;
- tema giorno/notte automatico basato su alba e tramonto;
- palette grafica ispirata al programma;
- sistema di build Windows con firma persistente e versionCode crescente.

## Build

Il progetto richiede Java 17, Gradle 8.9 e Android SDK 35.

Per la build automatica su Windows è incluso il pacchetto builder. Avvia:

```text
COMPILA_SUCCESSO_PLAYER_v21.bat
```

Il builder può predisporre automaticamente Java 17, Gradle e Android SDK quando non sono già disponibili.

## Pacchetto Android

- Application ID: `it.successoplayer.app`
- Versione: `3.3`
- Version code base: `3300`
